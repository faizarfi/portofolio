## 🚀 Memulai (Local Development)

### Prasyarat
- [Node.js](https://nodejs.org/) (versi 18+ direkomendasikan)
- npm / yarn / pnpm

### Instalasi & Menjalankan Proyek

1. **Clone repositori**:
   ```bash
   git clone https://github.com/faizarfi/portofolio.git
   cd portofolio
   ```

2. **Install dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan local development server**:
   ```bash
   npm run dev
   ```

4. Buka peramban di [http://localhost:3000](http://localhost:3000).

### Build untuk Produksi

```bash
npm run build
npm run start
```
